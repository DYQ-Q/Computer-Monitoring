# 方案B：电脑状态悬浮监控（Python + PySide6）

桌面常驻悬浮窗：实时显示 **CPU / 内存 / C盘**，内存快满时**右下角弹 Toast 告警**，
主打"打游戏 / 干活时不用开任务管理器也能防爆内存闪退"。

> 运行环境约束：所有 pip 安装**只进 conda 的 `agent` 环境**，不动全局和其他环境。

## 快速开始

```bat
:: 方式一：双击 run.bat（内部自动激活 agent 环境并静默启动）

:: 方式二：手动
conda activate agent
cd /d D:\project_DIY\电脑系统监测\方案B_Python_PySide6
python main.py
```

首次使用先装依赖（仅 agent 环境）：

```bat
conda activate agent
pip install -r requirements.txt
```

## 功能与操作

| 操作 | 效果 |
|---|---|
| 左键拖动悬浮窗 | 移动位置（自动保存到 config.json） |
| 左键双击 | 迷你条 / 完整面板 切换 |
| 右键悬浮窗 | 折叠、点击穿透、**背景不透明度**、隐藏、退出 |
| Ctrl + 滚轮 | 调节背景不透明度（实时预览） |
| 双击托盘图标 | 显示 / 隐藏悬浮窗 |
| 托盘右键 | 显示/隐藏、**C盘增长报告**、折叠、**点击穿透**、**背景不透明度**、**开机自启**、关于、退出 |

- **迷你条**：CPU / MEM 两条占用条 + C盘剩余，够小不挡视线
- **完整面板**：另加 CPU / 内存 2 分钟走势曲线、内存绝对值、C盘用量条
- **点击穿透**：开启后鼠标直接穿过悬浮窗（打游戏不误触），从托盘菜单关闭
- **告警**（右下角 Toast，不抢焦点、鼠标穿透、6 秒自动消失）：
  - 内存占用 ≥ 阈值（默认 85%）持续 10 秒 → "内存即将耗尽"
  - C盘剩余 ≤ 10 GB → "C盘空间不足"
  - C盘剩余较上次扫描下降 ≥ 2 GB → Toast 直接点名增长最大的目录

## C盘增长侦探（v0.2）

托盘（或悬浮窗）右键 → **"C盘增长报告"**，回答"谁在吃我的C盘"。

- **原理**：定时对重点目录做体积统计（快照）→ 与上次/基线差值对比 → 增长排行。
  不需要管理员权限、不装驱动、不读文件内容。
- **覆盖范围**：用户目录（含 AppData、微信/QQ 文件、下载、桌面）、系统 Temp、
  Windows 更新缓存、ProgramData、回收站；"深度扫描"另加 Windows / Program Files（较慢）。
- **自动化**：启动 45 秒后自动建基线，之后每 6 小时自动扫描（可配置）；
  扫描完成 Toast 摘要，剩余空间明显下降时点名"元凶"。
- **报告窗口**：当前用量、增长排行（本次/距基线）、文件数、权限跳过目录提示、
  "立即扫描 / 重建基线 / 深度扫描"开关。
- **性能**：扫描在后台线程进行，不卡 UI；退出程序时毫秒级中止；
  快照存 `data/snapshot.json`（几百 KB）。
- **权限说明**：无权限目录（如 `C:\Windows\Installer`、其他用户资料）自动跳过并在报告标注；
  秒级实时追踪（NTFS USN Journal）才真正需要管理员，留作后续可选项。

## 配置（config.json，程序根目录）

| 键 | 默认 | 说明 |
|---|---|---|
| `interval_ms` | 1000 | 采样间隔（毫秒） |
| `memory_alert_threshold` | 85 | 内存告警阈值（%） |
| `memory_alert_hold_seconds` | 10 | 超阈值持续多久才告警（防抖） |
| `memory_alert_cooldown_seconds` | 300 | 两次内存告警最小间隔 |
| `disk_alert_min_gb` | 10 | C盘剩余低于该值告警（GB） |
| `cpu_alert_threshold` | 0 | CPU 占用告警阈值，0=关闭 |
| `overlay_x / overlay_y` | -1 / 40 | 位置，-1=自动停靠右上角 |
| `compact` / `click_through` / `show_overlay` | false | 界面状态（也可在界面/托盘切换） |
| `bg_opacity` | 0.8 | 悬浮窗背景不透明度 0~1，**只影响背景**（文字、占用条不受影响，可全透明） |
| `diskwatch_enabled` | true | C盘增长侦探自动扫描开关（手动扫描不受影响） |
| `diskwatch_interval_hours` | 6 | 自动扫描间隔（小时） |
| `diskwatch_deep_scan` | false | 深度扫描：额外包含 Windows / Program Files（较慢） |

## 已知限制

- 悬浮窗对"独占全屏"程序不可见（无边框窗口/窗口化没问题）；
  独占全屏时告警仍会以 Toast 形式弹出。
- 若其他程序也是"置顶"，悬浮窗可能被盖住，双击托盘图标重新显示即可。
- 点击穿透开启后悬浮窗不接收任何鼠标事件，只能从托盘菜单关闭（开启时会有 Toast 提示）。
- 背景不透明度调到 0 时，只有文字/进度条所在的像素能"接住"鼠标
  （Windows 对完全透明的像素直接穿透），拖动时请抓文字或进度条位置。

  （本次/距基线双维度，父子目录自动去重，只看真正的元凶）。
- 新增：C盘增长报告窗口（托盘/悬浮窗右键打开）：当前用量、增长排行、
  立即扫描、重建基线、深度扫描开关、权限跳过提示。
- 新增：自动扫描（启动 45 秒建基线，默认每 6 小时一次）；C盘剩余较上次
  下降 ≥ 2GB 时 Toast 直接点名增长最大的目录。
- 技术：扫描器跳过 junction/符号链接（防环）、无权限目录自动跳过并标注；
  后台线程扫描、退出时毫秒级中止；快照存 data/snapshot.json。

### v0.1.1
- 修复：CPU 占用一直显示 0%。改为对 `cpu_times` 做差值计算（不再用
  `psutil.cpu_percent` 的全局状态）；低于 10% 时显示一位小数，
  空闲时的 0.4% 不再被显示成 "0%"。
- 修复：开启"点击穿透"后悬浮窗消失。改用 Windows 原生扩展样式
  （WS_EX_TRANSPARENT）直接切换，不销毁重建窗口，切换无闪烁；
  开启时弹 Toast 提示如何关闭。
- 新增：背景不透明度调节。右键菜单滑条 / Ctrl+滚轮 实时调节，
  只影响背景（可全透明），文字与占用条保持清晰；配置存 `bg_opacity`。
